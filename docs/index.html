Method
  • Source. GitHub search API, PRs authored by octodev and closed between 27 Aug 2025 - 27 Aug 2026: . Co-authored or reviewed work is not included.
  • Business days. . Public holidays come from the country chosen in Settings; personal days off are listed there too. Any day off not on the list still inflates the denominator, so the per-day rate is a floor.
  • Lines of code. Counted only for , and only for PRs under changed lines. Squash merges mean a diff is counted once, at merge time.
  • Issues. Counted by creation date, not close date: these are issues opened by this account.
  • Privacy. This page is self-contained. Settings live in this browser only; nothing is sent anywhere.
