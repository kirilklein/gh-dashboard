# For coding agents

Read this before changing anything. It is short on purpose.

## What this is

A one-page, self-contained dashboard of one GitHub account's rolling year. Everything lives in the
`mergeprint/` package: `cli.py` (interactive entry point, `mergeprint`) runs `collect.py` (gh CLI
-> `raw.json`) then `build.py` (raw + config + holidays inlined into `template.html` -> one HTML
file). Data files are written to the current directory. No dependencies beyond Python 3.9+ and `gh`.

## Privacy rules (do not weaken)

- `raw.json`, `out/`, `config.local.json` are git-ignored. Never commit them, never suggest committing them.
- The tracked `docs/index.html` is the **demo** built from `demo/raw.json` (synthetic, account `octodev`),
  served by GitHub Pages. Rebuild it only with `./demo.sh`. Never build real data into `docs/`.
- The page must stay self-contained and make no network requests except Google Fonts. No analytics.
- `build.py` inlines timestamps, sizes and repository names only. Never add titles, bodies, URLs or
  commit messages to the inlined data.
- `--public-only` / `--exclude-repo` exist on both `collect.py` (so private data never touches disk)
  and `build.py`. Keep both working.

## Where things live

| Change | File |
|---|---|
| Prompts and defaults of the one-command flow | `mergeprint/cli.py` |
| What is fetched | `mergeprint/collect.py` (search queries, `gh pr list` for sizes) |
| What is inlined | `mergeprint/build.py` (`data` dict) |
| Every number and chart | `mergeprint/template.html`: `compute()` aggregates, `render()` draws |
| Settings drawer (country, timezone, days off, events) | `template.html`, `/* settings UI */` block; stored in `localStorage` |
| Public holiday table | `mergeprint/holidays.json`, regenerated by `tools/gen_holidays.py` (needs `pip install holidays`) |
| Defaults | `mergeprint/config.json` (packaged) overlaid by `./config.local.json` (personal, ignored) |
| Packaging | `pyproject.toml` (stdlib only; `uvx --from . mergeprint` to try a change) |
| Demo data | `demo/generate.py` (deterministic seed), `demo/config.json` |

Aggregation runs in the browser so that settings changes need no rebuild. If you add a metric, add
it to `compute()` and read it in `render()`; do not move computation back into Python.

## Charts

Inline SVG, no library. Each chart is an IIFE inside `render()` that clears its `<svg>` and redraws;
`nice()` picks axis steps, `hoverColumns()` adds a hover cursor + tooltip to line charts, any element
with `data-tip` gets a tooltip. Colours are CSS variables that already have light and dark values.

## Check your work

```
./demo.sh                      # rebuilds docs/index.html from synthetic data
python3 -m py_compile mergeprint/*.py demo/*.py tools/*.py
uvx --from . mergeprint --help
```
Open `docs/index.html` in a browser, toggle the theme, change the country, click a repository row.
